What gets overwritten

Nothing, unless you ask. Each entry goes to the vault once. Export again next month and only the new ones go.

A note keeps its file name for good. Rename a subject or the case later and the links still reach the same note, showing the new name. A new entry never takes a file name already used in the vault, even one you deleted here.

An entry you edit after exporting is marked as changed, and stays out of the next export until you tick the box above.

The saved file keeps this record. Save a copy after each export, so the file knows what went to the vault.

Nothing here is uploaded or sent anywhere. This browser keeps the case between visits; the file from Save a copy is the record.
